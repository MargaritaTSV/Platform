Вам дан список различных механизмов энерговыделения, которые для
разных объектов являются основными источниками энергии. Сопоставьте механизмы
энерговыделения и объекты.

\begin{itemize}
  \item A — Радиоактивный распад
  \item B — Термоядерный синтез гелия
  \item C — Энергия вращения
  \item D — Гравитационная энергия сжатия
  \item E — Тепловая энергия
\end{itemize}

Порядок ответов:
\begin{enumerate}[label=\arabic*)]
  \item Протозвёзды
  \item Оболочки сверхновых типа Ia
  \item Белые карлики
  \item Радиопульсары
  \item Звёзды на стадии Главной последовательности
\end{enumerate}
